# 쩡마술사 링크 모음

카카오톡 대화 내보내기 파일에서 특정 사람이 올린 링크만 골라 중복 없이 모아 보는 페이지.

## 로컬 서버로 실행 (썸네일·제목·관련 자료)

```bash
pip install pillow          # 선택: 썸네일을 작게 줄여 JSON 에 저장
ollama pull bge-m3          # 선택: 관련 자료를 의미 기준으로 찾기
python server.py            # http://127.0.0.1:8765 이 열림
```

- 링크는 `links.json` 에 저장된다 (`--data` 로 경로 변경).
- 새 링크를 저장하면 각 페이지의 og 태그(제목·설명·대표 이미지)를 자동으로 가져온다.
- Ollama 가 켜져 있으면 `bge-m3` 임베딩으로, 없으면 제목·설명의 글자 비교(TF-IDF)로 관련 자료를 찾는다.
- 다른 임베딩 모델: `python server.py --model nomic-embed-text` (한국어는 bge-m3 권장)

## 아티팩트(웹)와 함께 쓰기

아티팩트 페이지는 외부 사이트에 접속할 수 없어서 썸네일을 직접 가져오지 못한다.
로컬에서 `백업(JSON)` → 아티팩트에서 `백업 불러오기` 하면 제목·썸네일·벡터가 합쳐진다.
반대로 아티팩트의 백업을 로컬 서버 페이지에서 불러와 옮길 수도 있다.
